## What round 4 must do — the vertical slice „Startseite"

Only the home screen and what hangs directly off it. Everything else (Schulden / Einkommen / Saldo views, Verträge, Statistik, complex month analysis) is OUT of this round; list them once in the intro as „kommt in den nächsten Runden" so the user sees they are noted.

### A) Mapping view — „Was gehört auf die Startseite?" (`data-view="r4-home-uses"`, `data-view-kind="mapping"`, `data-view-for="r4home"`)

Items = home use cases (≈ 14–18, ids snake_case), e.g.: im_plan_status, frei_heute, frei_woche, topf_budgets, zeit_vs_linear (where am I vs linear spending), eilmeldung, fragen_offen, als_naechstes_top3, aktualitaet, wusstest_du_schon, haushalt_person_wechsel, zoom_heute_woche_monat_jahr, unkategorisiert_hinweis, notgroschen, punkte_fortschritt, monat_kurzfazit, vertraege_faellig, statistik_einstieg, persoenliche_toepfe.

Targets as **axes** (matrix, no schematic needed) with a context axis for form factor if the engine supports context values (≤ 4: Handy, Desktop); otherwise two matrices or one axis set per form factor. Columns:
- `top` — „Sofort sichtbar"
- `kontext` — „Nur wenn relevant" (appears when something is up)
- `umschalten` — „Per Umschalten / Wischen" (zoom, Haushalt ⇄ Person)
- `hinter_icon` — „Hinter einem Icon / einer Unterseite"
- `nicht_start` — „Nicht auf der Startseite"

Pre-fill a sensible `proposal` (mandatory): e.g. Handy top = im_plan_status, frei_heute, topf_budgets (compact), zeit_vs_linear (inside the tank); kontext = eilmeldung, unkategorisiert_hinweis, wusstest_du_schon (Haushalt only); umschalten = zoom, haushalt_person_wechsel, frei_woche; hinter_icon = fragen_offen (motivating icon top-right with badge), aktualitaet (icon), punkte_fortschritt, statistik_einstieg, vertraege_faellig; nicht_start = monat_kurzfazit? (or top 3 in Monat zoom) … Desktop: more in top (als_naechstes_top3, frei_woche, monat_kurzfazit, vertraege_faellig as a side column). Note channel per the design-round rule (dock view note, no inline note).

### B) The home design `r4home` — screens (all wired with `data-screen-link`)

Base: r3b's zoom concept (segments Heute · Woche · Monat · Jahr at the top — „Zyklus" is renamed **Monat**), Budget-Tank language.

1. `r4-s1` **Heute · Person (Handy)** — answers the two intents of „Heute": (1) „Im Plan?" one clear verdict, (2) „Wie viel kann ich heute / diese Woche noch ausgeben?" per pot. The tank gets the **time aspect**: a diagonal/linear „Soll-Linie" (where the level should be today if spending linearly over the month) vs. the actual level — the gap is the message (ahead/behind). Below: compact pot budgets (Lebensmittel, Freizeit, Notgroschen …) as „heute x € · Woche y €". Top bar: Android-style **notification pill top centre** („1 Eilmeldung") when there is one, **freshness icon** (green dot / check, tooltip-free label „aktuell") top left, **motivating questions icon** top right with badge (3). „Als Nächstes" top 3 + „mehr anzeigen". Swipe hint dots for Person ⇄ Haushalt.
2. `r4-s2` **Heute · Haushalt** (after swiping) — shared tank, both persons small, „Wusstest du schon?" one-liner (the current main deviation vs. benchmark, neutral tone, not addressed at a person), link/icon to Statistik.
3. `r4-s3` **Woche** — intents: „Was kommt auf mich zu?" (upcoming debits this week, top 3 + mehr) and „Wie stehe ich in der Woche?" (week tank / bar vs plan, pro-rata note only if the week crosses month end).
4. `r4-s4` **Eilmeldung geöffnet** — the pill expanded into a card stack, each with actions („Ist in Ordnung", „Prüfen"); after the last one, back to home with the pill gone.
5. `r4-s5` **Fragen · Karteikarten** — one booking per card („REWE 64,12 € · Mi" → Kategorie? Für wen?), big tap targets, progress „7 / 15 bis zum nächsten Punkt" with a themed counter, swipe/tap to next card; meanwhile the bookings are shown as „unkategorisiert" on home.
6. `r4-s6` **Punkt erreicht** — celebration state (CSS-only confetti/burst shapes, no script; a static „animated" look is fine, `@keyframes` allowed in the top `<style>` if the gate permits), then „Weiter" (more cards) or „Zur Startseite".
7. `r4-s7` **Datenstand** (via freshness icon) — „Aktuell · Stand 06:30 · nächster Abruf 06:30 morgen", per bank last fetch + budget left, import log (time, trigger manuell/geplant/Panel, Rohdaten vs Aufbereitung, version e.g. „Verarbeitung v3"), and a **Monats-Validität** list: each calendar month with a check „Summe Konten = Summe Töpfe + frei + unzugeordnet → ✓ / Differenz 12,40 €" — the „test result" the user asked for.
8. `r4-s8` **Desktop-Startseite** — same content, desktop frame uses the width: main column = tank + pots, right column pulls in from sub-pages (Als Nächstes full list, Woche ahead, Monat Kurzfazit, Verträge fällig). Make it explicit that the complex month analysis lives only here (a „Monatsanalyse öffnen" entry that exists only on desktop; mobile shows „Monat kurz").

Persönliche Töpfe: show at least one personal pot in the person view (fed from a personal account, labelled), shared pots in Haushalt.
