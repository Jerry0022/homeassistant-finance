# README and web handbook — outline

The README stays short (what Finance is, install via HACS, first steps, security model). The web
handbook explains the whole product. Outline:

1. **What Finance is for** — "Are we on plan, and what needs doing?"; plan vs. actual.
2. **Getting started** — Enable Banking application, adding a bank, the setup wizard step by step.
3. **The household** — persons, accounts and owners, mine / yours / ours, privacy between members.
4. **Plan** — cost positions, income, salary cycle, reserves and virtual pots, savings goals.
5. **Daily, weekly, per cycle, yearly** — glance, weekly check and review inbox, cycle close and
   settle-up, yearly review.
6. **Categories and rules** — corrections and their reach, tolerances, learned merchants, optional
   AI (providers, budget, what is sent).
7. **Links** — own-account transfers, PayPal, duplicates, refunds, merged bookings, credit cards.
8. **Contracts and subscriptions** — detection, price mechanism, contract model, notice reminders.
9. **Benchmarks** — regions, dimensions, sources and years, median vs. mean.
10. **Points** — how the points event works and how to connect a points system.
11. **Notifications and automations** — exception types, digest, events, sensors.
12. **Data and security** — encrypted storage, live-fetch limits, what leaves the house.
13. **FAQ / troubleshooting** — consent renewal, rate limits, rebuilding from raw.
